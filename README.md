# Split Bill API

Backend Java/Spring Boot para controle de despesas compartilhadas.

## Stack

- Java 21
- Spring Boot 3.5.14
- PostgreSQL
- Flyway
- Arquitetura hexagonal

## Desenvolvimento

```bash
docker compose up -d
mvn spring-boot:run
```
